# Security

Report a vulnerability in dashq or a dashq release privately to the repository owner, [@alexkirs](https://github.com/alexkirs), by direct message or the contact on that GitHub profile. Do not open an issue, pull request or comment for it. This repository is private, so GitHub's "Report a vulnerability" form is not available.

Expect an acknowledgement within 7 days. A confirmed report gets a fix or a documented mitigation before any disclosure.

Rules the fix follows: [security baseline](https://github.com/taskqorg/specq/blob/main/engineering/security.md).
